# RoboAtlas

**Understand the Robot. Map the Industry.**

一个面向机器人与具身智能行业的交互式产业知识图谱。

## RoboAtlas 是什么

RoboAtlas 从一台机器人整机出发，连接机器人类型、系统、零部件、技术、产业链与应用，帮助机器人行业新人、销售、产品经理和研究者快速建立产业认知。

```text
机器人类型 → 系统 → 零部件 → 技术 → 产业链 → 应用
```

它不是传统机器人百科，而是一个可以从机器人本体进入产业世界的可视化探索空间。

## 当前功能

- 机器人类型图鉴与六类机器人切换
- 基于身体部位的热点探索
- 零部件知识详情与关联节点
- 上游、核心零部件、下游机器人和应用场景关系
- 独立滚动的机器人入门知识工作区
- 面向销售新人的静态销售知识助手
- 机器人、组件、知识和产业关系的关联跳转

## 当前支持的机器人

- 人形机器人
- 协作机器人
- 工业机器人
- AMR / AGV
- 四足机器人
- 服务机器人

## 核心零部件

| 方向 | 内容 |
| --- | --- |
| 运动执行 | 机器人关节、减速器、电机、编码器、伺服系统 |
| 感知 | 六维力传感器、LiDAR、IMU、深度相机、3D 视觉、触觉传感器 |

## 项目理念

机器人产业知识通常分散在产品手册、供应商资料和行业报告中。RoboAtlas 希望以空间化、可关联的交互方式，让用户从“一台机器人”开始，逐步理解它背后的技术结构与产业关系。

## 本地运行

RoboAtlas 是原生 ES Modules 的静态网站，无需安装依赖或执行构建。

需要 Node.js 18 或更高版本：

```sh
node server.mjs
```

然后打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

也可以使用任意支持静态文件服务的本地服务器，并将 `dist/` 作为网站根目录。不要直接双击打开 `index.html`，以免浏览器拦截 ES Modules 的模块加载。

## 开发路线

- 更完整的机器人与零部件数据库
- 更丰富的 3D 与空间交互视觉
- 企业、供应商和应用知识
- 更强的搜索与知识关系浏览
- 多语言内容
- 可选的 AI / RAG 扩展

当前版本不包含真实 AI Agent 或在线模型调用；销售助手是可审阅的静态销售知识内容。
